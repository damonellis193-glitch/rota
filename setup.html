Step 1: Set Up Your Spreadsheet

  1. Open the configured Google Sheet:
    Open Team Rota Spreadsheet
  2. Make sure you have Editor access to this spreadsheet
  3. The app will automatically create the necessary sheets on first run
  4. Add employees to the Employees sheet with these columns:
    • Name - Employee's full name
    • Email - Their Google email address
    • Annual Allowance - Holiday days per year
    • Role - "Admin", "Manager", or "User"
    • Manager - Their manager's name (optional)
    • Department - Department name (optional)
    • CarryOver - Days carried over (optional)
💡 Admin Access: Users with Role set to "Admin" in the Employees sheet will have admin access. No need to configure emails in code!

Step 2: Deploy the Web App

  1. In the Apps Script editor, click Deploy → New deployment
  2. Click the gear icon ⚙️ next to "Select type"
  3. Choose Web app
  4. Configure:
    • Description: Team Rota v1
    • Execute as: Me (your email)
    • Who has access: Anyone (or your organization)
  5. Click Deploy
  6. Grant necessary permissions when prompted
  7. Copy the Web App URL

Step 3: Access the App

  1. Open the Web App URL you copied in Step 2
  2. The app will automatically create the necessary database sheets
  3. You'll see the main app interface
  4. Add employees via the Employees sheet in your Google Spreadsheet
