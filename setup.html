🛠️ Team Rota - Setup Required

⚠️ Configuration Incomplete

The Rota app is not yet configured. Please follow the steps below to complete setup.

Step 1: Create Your Google Sheet

  1. Go to Google Sheets
  2. Create a new blank spreadsheet
  3. Name it something like "Team Rota Database"
  4. Copy the Spreadsheet ID from the URL:
    https://docs.google.com/spreadsheets/d/1a2B3c4D5e6F7g8H9i0J/edit
    ⬆️ Copy only the highlighted ID portion (the long string between /d/ and /edit)

Step 2: Update Configuration in code.gs

  1. In the Apps Script editor, open code.gs
  2. Find these lines at the top: 
    const SPREADSHEET_ID = 'YOUR_SPREADSHEET_ID_HERE';
const ADMIN_EMAILS = ['your_email@domain.com'];
  3. Replace YOUR_SPREADSHEET_ID_HERE with your actual Spreadsheet ID from Step 1
    Example: const SPREADSHEET_ID = '1a2B3c4D5e6F7g8H9i0J';
  4. Replace your_email@domain.com with your Google email address
    Example: const ADMIN_EMAILS = ['alice@company.com'];
  5. Save the file (Ctrl+S or Cmd+S)

Step 3: Deploy the Web App

  1. Click Deploy → New deployment
  2. Click the gear icon ⚙️ next to "Select type"
  3. Choose Web app
  4. Configure:
    • Description: Team Rota v1
    • Execute as: Me (your email)
    • Who has access: Anyone (or your organization)
  5. Click Deploy
  6. Grant necessary permissions when prompted
  7. Copy the Web App URL

Step 4: Access the App

  1. Open the Web App URL you copied in Step 3
  2. The app will automatically create the necessary database sheets
  3. You'll see the main app interface
  4. Go to the Admin panel to add employees
✅ Need Help?

After completing setup, you can test your configuration by visiting:

YOUR_WEB_APP_URL?page=diagnostic

This will run automated tests to verify everything is working correctly.
